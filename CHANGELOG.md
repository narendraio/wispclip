# Changelog

## 1.0 — 2026-09-23

First open-source release.

- Clipboard history for text, rich text, images and files (last 300 items), opened with ⌃⌘V
- Pinned items and snippets
- Search, type filters, quick paste with ⌘1…⌘9, paste as plain text
- Smart detection for JSON, SQL, UUIDs, JWTs, links, emails and colors
- ⌘K transforms (JSON, SQL, case, lines, URL/Base64, UUID/timestamp)
- Copy sounds, pause recording, open at login
