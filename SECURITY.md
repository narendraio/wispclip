# Security

Wisp stores your clipboard history locally in `~/Library/Application Support/ClipBoard/` and makes no network requests. It skips copies that password managers mark as concealed or transient.

If you find a security issue, please **don't open a public issue**. Report it privately through [GitHub's private vulnerability reporting](https://github.com/narendraio/wispclip/security/advisories/new) and we'll get back to you as soon as we can.
